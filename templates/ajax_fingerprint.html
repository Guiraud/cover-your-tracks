Résultats détaillés

Voici des informations plus détaillées recueillies sur votre navigateur. Votre rapport comprend plusieurs types de métriques :

En-têtes Web

Chaque fois que vous vous connectez à un site Web (ici « https://{{ config.get('SITE_DOMAIN') }} »), votre appareil envoie une requête qui inclut des en-têtes HTTP. Ces en-têtes contiennent des informations telles que le fuseau horaire de votre appareil, sa langue, ses paramètres de confidentialité et ses cookies. Les en-têtes Web sont transmis par votre navigateur à chaque visite de site.

Caractéristiques obtenues via JavaScript

Certains détails de votre navigateur peuvent être découverts à l'aide de code JavaScript. Cela inclut les polices installées, certaines informations sur votre configuration matérielle et votre empreinte Canvas.
